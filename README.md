## Descripción

PokeMemory es un juego de memoria desarrollado con HTML, CSS y JavaScript, utilizando Vite y PokeAPI.

Permite crear un perfil, seleccionar un Pokémon favorito, jugar partidas con diferentes cantidades de cartas y consultar un ranking de resultados.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Vite
- PokeAPI
- sessionStorage y localStorage
- Vercel
